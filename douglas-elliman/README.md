# Douglas Elliman: logos for sugar paper

Updated Nov 4, 2026.

## Print this
`DouglasElliman_Square2.5_Circle3.5.pdf`
- One square logo, exactly 2.5 x 2.5 in (outer edge of the border).
- One circle logo, exactly 3.5 in across (outer edge of the ring).
- Top half of a US Letter page, 0.5 in top margin. Bottom half blank.
- Logos are embedded as 600 dpi images so every PDF viewer shows them.
- Checked in two viewers (Poppler and pdf.js): both measure 2.50 in and 3.50 in.
- Load sugar paper in the Epson, print at 100% (Actual size).

## Single logos
- `DouglasElliman_Square_2.5in_600dpi.png`, `DouglasElliman_Circle_3.5in_600dpi.png`: 600 dpi.
- `.svg` files: vector masters.
