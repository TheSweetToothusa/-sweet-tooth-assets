# Douglas Elliman: large logo chocolate bar

Made Nov 4, 2026 for the Douglas Elliman Florida gifting account.

## Logo source
- Official Douglas Elliman logo, vector, taken from the header of https://www.elliman.com/offices (Nov 4, 2026).
- No separate logo was found for the MiMo office (5555 Biscayne Blvd). Jay Parker's email signature (Sep 11, 2026) is text only, no logo image. So this uses the regular logo.

## Size
- Product: Custom Logo Bars, Large 6.3 x 4 in.
- Prints on the dashboard's "Plaque B" shape, 6.4 x 4 in, 2 per US Letter sheet.

| File | What it is |
